# VoltMind dashboard review — 11 October 2026

This review repairs the running project in <project>. It does not retrain classifiers or change the supplied datasets.

## Changes

- Restored the visible mouse pointer. Fixed navigation overlap and made its full list horizontally scrollable.
- Temperature hover opens a viewport-floating card with that point's IST timestamp, two-decimal actual/expected/difference, loading, ambient, readiness and detector state. Click selects a reading; the keyboard slider inspects every original point. Evidence dialogs now mount at the document body rather than inside transformed page sections.
- Temperature time uses a numeric time axis with explicit readable ticks. Actual is black and expected is orange/dashed. Grey bands expose unavailable intervals and exact missing-value counts. Optional dotted bridges interpolate only between real endpoints across at most three missing five-minute readings; values never enter models, evidence, reports or measured-value tooltips. Long gaps stay unavailable.
- Added a genuine floating question interface at the bottom right. The local evidence assistant answers supported questions from a freshly requested backend summary, with processed-row scope and snapshot time. It covers detections, temperature, loading, gaps, health, calibration, maintenance, recurrence and Thermal DNA. Unsupported questions return a clear scope message. This is a deterministic evidence assistant, not an external general-purpose language model.
- Eight detailed summaries and report downloads remain inside the assistant's expandable evidence section. Conversation replies link to supporting evidence.
- Added a prominent incident counter strip, distinguishing warning incidents from readiness events. Two-hour summaries explicitly mention optional oil/terminal indications independently of the numeric thermal/electrical score.
- Batched screen updates to five per second during fast playback, retaining every delivered measurement. Dense charts draw representative points preserving minima/maxima, null boundaries and detector state transitions; every original point remains available in the slider and exports. In the 4,032-row check, the temperature chart used 840 representative points. Removed the duplicate temperature plot from the default electrical telemetry view.
- Fixed a backend summary bug: retained incidents from a previous replay could appear before the new replay reached their timestamps. Live summary/recurrence/evidence now include only incidents actually encountered in that session. Source records remain persisted and deduplicated.
- Renamed the schema/calibration section to Advanced upload settings (optional). It is file configuration, not a chatbot prompt.
